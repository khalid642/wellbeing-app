Focus modes (implement in wellbeing_app/daemon/focus_mode.py):

FocusMode enum: NORMAL, FOCUS, DEEP_FOCUS, PRAYER_MODE, SILENT

NORMAL: everything works normally
FOCUS: eye-care overlays still show; adhan plays but no lock overlay
DEEP_FOCUS: no eye-care overlays; adhan plays as notification only (no sound lock)
PRAYER_MODE: everything at full intensity; salah lock shows
SILENT: no audio, no overlays, no notifications (emergencies only)

Focus mode is stored in app_config table as 'focus_mode' key.
Daemon checks focus mode before every event and adjusts behavior.
Tray icon changes slightly per mode (different icon variant or color overlay).

DBus integration (wellbeing_app/dbus/__init__.py and wellbeing_app/dbus/service.py):

Register a DBus service: com.wellbeingapp.Daemon
Methods exposed:
  GetStatus() -> dict { daemon_running, current_prayer, next_prayer_time, focus_mode }
  SetFocusMode(mode: str)
  PauseEyeCare(minutes: int)
  TriggerAdhan(prayer_name: str)  (for testing)
  ShowOverlay(overlay_id: int)
  GetVersion() -> str

This allows external tools (scripts, i3 keybindings) to control the app via:
  dbus-send --session --dest=com.wellbeingapp.Daemon --type=method_call /com/wellbeingapp/Daemon com.wellbeingapp.Daemon.SetFocusMode string:SILENT
