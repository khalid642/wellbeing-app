ayah_widget.py
──────────────────────
AyahWidget(Gtk.Box)

Displays a Quran verse.

Config dict keys:
  surah: int
  ayah: int
  show_arabic: bool (default True)
  show_translation: bool (default True)
  translation_language: str (default 'en')

Data source: load from data/quran/quran_simple.json
JSON structure:
  {
    "1": {
      "name": "Al-Fatiha",
      "verses": {
        "1": { "arabic": "بِسْمِ اللَّهِ...", "en": "In the name of Allah..." },
        ...
      }
    }
  }

Create this JSON file with at minimum:
  Surah 1 (Al-Fatiha) all 7 ayahs
  Surah 112 (Al-Ikhlas) all 4 ayahs
  Surah 113 (Al-Falaq) all 5 ayahs
  Surah 114 (An-Nas) all 6 ayahs

Visual layout (top to bottom):
  Surah name (small, centered, muted color)
  Arabic text (large, right-aligned, Arabic font)
  Translation text (medium, centered, slightly muted)
  Reference "Surah X : Ayah Y" (small, bottom right)

Arabic font: check if 'Amiri', 'Scheherazade New', or 'Noto Naskh Arabic' is installed
via Pango. Use first available. Fallback to system default.

PART 2 — ZIKR SEQUENCE ENGINE
────────────────────────────────────────────

Create wellbeing_app/overlay_engine/sequence_player.py — ZikrSequencePlayer

This handles showing multiple zikr widgets one after another inside ONE 
OverlayWindow instance.

How it works:
  OverlayWindow receives widgets list normally from overlay_widget_assignments.
  When a ZikrSequence is assigned to the 'zikr' slot instead of individual widgets,
  the ZikrSequencePlayer takes over widget display inside the overlay card.

ZikrSequencePlayer(card_container: Gtk.Box):
  Takes the overlay's inner card Gtk.Box as container.
  
  load_sequence(sequence_id: int):
    Loads zikr_sequences + zikr_steps from DB

  play():
    Iterates steps in step_order.
    For each step: select widgets per selection_mode, display them, wait duration, advance.

  Step selection modes:
    'fixed': use all widget_ids in step.widget_ids (JSON list of template IDs)
    'random_one': pick 1 randomly from widget_ids list
    'random_n': pick step.n_count randomly from widget_ids list

  Step display:
    Clear card_container content.
    Create widget instances for selected templates.
    Add to card_container.
    Call start_animations() on each.
    After step.duration_seconds: call stop_animations(), transition to next step.

  Transitions between steps (step.transition field):
    'fade': set card_container opacity 1→0 over 300ms, swap content, 0→1 over 300ms
    'instant': swap content immediately

  Loop modes (sequence.loop_mode):
    'once': play all steps, then emit 'sequence_complete'
    'loop': after last step, restart from step 1

  'sequence_complete' signal: OverlayWindow listens and calls self.destroy()

  Step indicator: at bottom of card, show dots (● ● ○ ○) for current/total steps.
  Update dot display on each step advance.

Integration:
  In overlay_widget_assignments, a slot can have either:
    A) Individual widget_template rows (existing system) — shown all at once stacked
    B) A single row with widget_type='zikr_sequence' and config_json containing
       { "sequence_id": 3 } — triggers ZikrSequencePlayer

  OverlayWindow.load_widgets() checks: if any widget is type 'zikr_sequence':
    Instantiate ZikrSequencePlayer and pass card_container to it.
  Otherwise: use existing stacked widget display.

PART 4 — SEQUENCE EDITOR GUI
────────────────────────────────────────────

Create wellbeing_app/gui/pages/zikr_editor.py — ZikrEditorPage

Add "Zikr" to sidebar navigation.

Left panel: list of saved sequences
  Each row: sequence name, step count, loop mode badge
  "New Sequence" button at bottom
  Delete button per row (with confirmation)

Right panel (when sequence selected):
  Sequence name: editable Gtk.Entry at top
  Loop mode: DropDown (Once / Loop)

  Steps list (Gtk.ListBox):
    Each step shown as a row:
      Step number label
      Selection mode badge (Fixed / Random 1 / Random N)
      Duration label (e.g. "60s")
      Expand arrow button

    Expanded step editor (inside AdwExpanderRow):
      Selection mode: DropDown (Fixed / Random One / Random N)
      N count: SpinButton (visible only if Random N selected)
      Widget picker: list of checkboxes, one per widget_template
        Show: type icon, template name, category
        Checked = included in this step's pool
      Duration: SpinButton (seconds, 1–3600)
      Transition: DropDown (Fade / Instant)

    "Add Step" button below list
    Drag handle on each row for reorder (Gtk.DragSource + Gtk.DropTarget)

  "Preview Sequence" button:
    Immediately shows OverlayWindow in unlocked mode with ZikrSequencePlayer
    loaded with the currently edited sequence (saves first)

Save all changes to DB immediately on any field change (no explicit Save button).
