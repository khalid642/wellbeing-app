Phase 8 — Dashboard & Main Window GUI (QML / Qt Quick Edition)

Build the main application window and dashboard using QML and Qt Quick. This must 
look like a modern, polished desktop application following native design patterns. 
Follow every instruction exactly — do not guess icon names, do not use legacy 
Qt Quick Controls 1 patterns, and ensure strict type safety for properties.

────────────────────────────────────────────
CRITICAL QML RULES — READ BEFORE WRITING CODE
────────────────────────────────────────────

1. NEVER use absolute positioning (x, y) or hardcoded element sizing for responsive 
   layouts. Use Layout-based attached properties (Layout.fillWidth: true, 
   Layout.fillHeight: true, Layout.preferredWidth) inside RowLayout and ColumnLayout.
   Reserve anchors ONLY for items inside a plain Item, Rectangle, or Page.

2. NEVER use legacy Qt Quick Controls 1 modules. Use ONLY:
   import QtQuick
   import QtQuick.Controls
   import QtQuick.Layouts
   (And optionally import org.kde.kirigami if targeting a Kirigami desktop look).

3. NEVER use JavaScript logic blocks inside bindings to push data downstream. Use 
   declarative property bindings so that UI components automatically update when 
   the underlying C++ or PySide/PyQt context properties change.

4. NEVER guess Freedesktop/KDE/Qt icon names. Use ONLY these verified cross-platform 
   system icon names available in standard themes:
   "go-next"
   "go-previous"
   "list-add"
   "edit-delete"
   "emblem-success-symbolic" or "dialog-ok"
   "dialog-warning"
   "audio-volume-high"
   "configure"
   "view-refresh"
   "weather-clear"
   "document-save"
   "document-open"
   "media-playback-start"
   "media-playback-stop"
   "preferences-system"
   "system-shutdown"
   "help-about"
   "open-menu"
   "go-down"
   "go-right"
   "edit-clear"

   For missing concepts, use a plain Rectangle with a subtle color as a placeholder.

5. NEVER use complex inline multi-line JavaScript inside signals. Move complex logic 
   to the Python/C++ backend wrapper or separate helper JS functions.

6. For styling and customization, define an application-wide palette or use the built-in 
   Qt Quick Controls 2 styling configuration (e.g., Material, Fusion, or Breeze). Pass custom 
   CSS-like visual adjustments via custom QML components or graphical Item properties.
