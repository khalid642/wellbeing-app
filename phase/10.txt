Enhance ZikrSequencePlayer:

Weighted random selection:
  When selection_mode='random_one' or 'random_n' AND weighted_probabilities is set:
  Use weighted random selection: widget with weight 3.0 is 3x more likely than weight 1.0
  Implement using Python's random.choices(population, weights)

Conditional display:
  conditions_json format: { "prayer": "fajr", "time_after": "sunset", "day_of_week": [0,4] }
  Before showing a step, evaluate conditions:
    - prayer: only show if current prayer matches
    - time_after/time_before: only show if current time is after/before specified event
    - day_of_week: 0=Monday, 6=Sunday
  If conditions not met: skip this step

Loop modes:
  'once': play all steps once then emit sequence_complete
  'loop': loop entire sequence indefinitely
  'infinite': loop but allow user to advance/dismiss at any time
  'manual': user presses key/click to advance to next step (duration becomes max_duration)

User advance controls:
  In non-locked overlays: show subtle "→ Next" button or detect right arrow key
  In 'manual' mode: pressing Space/Enter/Right Arrow advances to next step

Right panel (when sequence selected): sequence detail editor
  Sequence name field (editable)
  Loop mode dropdown
  
  Steps list (Gtk.ListBox, drag-to-reorder using Gtk.DragSource/Gtk.DropTarget):

      - Selection mode badge (Fixed/Random1/RandomN)

      - Duration

      - Transition: DropDown (fade/slide_left/slide_up/instant)
      - Conditions: expandable section with prayer/time/day conditions
      - Weighted probabilities: sliders for each selected widget (only if random mode)
  
  "Preview Sequence" button → launches ZikrOverlay with this sequence immediately
